# Week 09 Grading Checklist: List Menu App

Use this as a quick grading aid alongside the student's code, notes, and PR.

## Required Project

- [ ] Create a list to store several items.
- [ ] Use a loop to keep the menu running until the user quits.
- [ ] Let the user add an item with `append()`.
- [ ] Let the user remove an item with `remove()` or `pop()`.
- [ ] Display the list using a loop, not only `print(my_list)`.
- [ ] Validate at least one user choice before changing the list.
- [ ] Print helpful messages after add, remove, and invalid actions.
- [ ] Include at least three test cases in `notes.md`, including an invalid remove.

## Stretch 1: Solid Extension

- [ ] Add search for an item in the list.
- [ ] Add sorting or alphabetical display.
- [ ] Keep the original add/remove/display behavior working.
- [ ] Add two more test cases for search or sorting.

## Stretch 2: Challenge Extension

- [ ] Store each item with extra information using nested lists or tuples.
- [ ] Add an edit/update option.
- [ ] Use helper functions for at least two menu actions.
- [ ] Add two more test cases for editing or nested data.
