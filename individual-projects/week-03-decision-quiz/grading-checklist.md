# Grading Checklist For Week 03: Decision Quiz Program

Branch to grade: `week-03-decision-quiz`

## Required Project

- [ ] Ask at least three questions.
- [ ] Use at least three if/elif/else decision blocks.
- [ ] Use at least two comparison operators.
- [ ] Keep score or track a recommendation category.
- [ ] Print different final messages for different outcomes.
- [ ] Use clear prompts and output labels.
- [ ] Program runs from top to bottom without syntax errors.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add input cleanup such as lower() or strip() for text answers.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Add nested decisions or a scoring system with at least three final categories.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
