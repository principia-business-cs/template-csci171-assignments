## Required Friday Project

Turn repeated turtle drawing into named functions that can be reused with different arguments.

The goal is not to build the largest possible program. The goal is to show that you can use this week's textbook concepts correctly and explain your choices.

## Requirements I Will Check

Your program must include all of these:

- [ ] Define at least two functions besides `main()`.
- [ ] Use at least one function parameter.
- [ ] Call one function more than once with different argument values.
- [ ] Use turtle drawing commands inside a function.
- [ ] Use a loop inside at least one function.
- [ ] Use clear function names that describe the action.
- [ ] Keep top-level code inside `main()` and call `main()` at the bottom.
- [ ] Include at least three test notes describing different function calls you tried.
