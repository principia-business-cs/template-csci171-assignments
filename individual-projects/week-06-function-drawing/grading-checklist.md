# Week 06 Grading Checklist: Function Drawing

Use this as a quick grading aid alongside the student's code, notes, and PR.

## Required Project

- [ ] Define at least two functions besides `main()`.
- [ ] Use at least one function parameter.
- [ ] Call one function more than once with different argument values.
- [ ] Use turtle drawing commands inside a function.
- [ ] Use a loop inside at least one function.
- [ ] Use clear function names that describe the action.
- [ ] Keep top-level code inside `main()` and call `main()` at the bottom.
- [ ] Include at least three test notes describing different function calls you tried.

## Stretch 1: Solid Extension

- [ ] Create a small scene by combining at least three reusable drawing functions.
- [ ] Use parameters for size or color in at least two functions.
- [ ] Keep repeated code inside functions instead of copying blocks.
- [ ] Add two more test notes for different parameter values.

## Stretch 2: Challenge Extension

- [ ] Write a function that draws a regular polygon with any number of sides.
- [ ] Use the polygon function to draw at least three different polygons.
- [ ] Use a helper function to move the turtle without drawing.
- [ ] Add two more test notes for different side counts.
