# Grading Checklist For Week 06: Function-Based Drawing

Branch to grade: `week-06-function-drawing`

## Required Project

- [ ] Define at least three functions.
- [ ] At least two functions must take parameters.
- [ ] Call each function at least once.
- [ ] Use a function to draw a repeated shape.
- [ ] Use meaningful function names.
- [ ] Keep the main program short and readable.
- [ ] Include docstrings or short comments for functions.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add a function that draws the same shape at different locations or sizes.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Create a small drawing library with at least five reusable functions and a final scene that uses them.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
