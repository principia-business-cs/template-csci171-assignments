## Required Friday Project

Analyze a piece of user-entered text and report useful facts about it.

## Requirements I Will Check

- [ ] Ask the user for a sentence or phrase.
- [ ] Use len() at least once.
- [ ] Use indexing or slicing at least once.
- [ ] Traverse the string with a loop.
- [ ] Count at least one kind of character or pattern.
- [ ] Use at least one string method such as lower(), strip(), or count().
- [ ] Print a clear summary.

## Expected Result
