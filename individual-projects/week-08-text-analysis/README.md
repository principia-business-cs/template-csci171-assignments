## Required Friday Project

Analyze text input and report counts or simple patterns.

The goal is not to build the largest possible program. The goal is to show that you can use this week's textbook concepts correctly and explain your choices.

## Requirements I Will Check

Your program must include all of these:

- [ ] Ask the user for a phrase or sentence with `input()`.
- [ ] Use `.lower()` or `.strip()` before analysis.
- [ ] Use `len()` to report the text length.
- [ ] Use a loop to traverse the string one character at a time.
- [ ] Count at least one kind of character, such as vowels, spaces, or a chosen letter.
- [ ] Use indexing or slicing at least once.
- [ ] Print a clear summary of the results.
- [ ] Include at least three test cases in `notes.md`, including mixed-case input.
