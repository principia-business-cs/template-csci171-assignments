# Week 08 Grading Checklist: Text Analyzer

Use this as a quick grading aid alongside the student's code, notes, and PR.

## Required Project

- [ ] Ask the user for a phrase or sentence with `input()`.
- [ ] Use `.lower()` or `.strip()` before analysis.
- [ ] Use `len()` to report the text length.
- [ ] Use a loop to traverse the string one character at a time.
- [ ] Count at least one kind of character, such as vowels, spaces, or a chosen letter.
- [ ] Use indexing or slicing at least once.
- [ ] Print a clear summary of the results.
- [ ] Include at least three test cases in `notes.md`, including mixed-case input.

## Stretch 1: Solid Extension

- [ ] Add case-insensitive search for a user-chosen letter or word.
- [ ] Count vowels and consonants separately.
- [ ] Keep spaces or punctuation from breaking the program.
- [ ] Add two more test cases for search behavior.

## Stretch 2: Challenge Extension

- [ ] Create a simple text score or readability-style summary.
- [ ] Use at least one helper function that returns a value.
- [ ] Use slicing to show a preview of the input.
- [ ] Add two more test cases for short and long text.
