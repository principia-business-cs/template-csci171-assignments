# Week 13 Grading Checklist: Event Toy

Use this as a quick grading aid alongside the student's code, notes, and PR.

## Required Project

- [ ] Create a turtle screen and turtle object.
- [ ] Define at least two event-handler functions.
- [ ] Connect handlers to keys or mouse clicks with event-listening methods.
- [ ] Use a state variable such as score, color, speed, or mode.
- [ ] Change something visible when an event happens.
- [ ] Print or display a short instruction for the user.
- [ ] Keep the program open long enough for interaction.
- [ ] Include at least three test cases in `notes.md` describing events you tried.

## Stretch 1: Solid Extension

- [ ] Add score, mode switching, or reset.
- [ ] Use at least three event handlers.
- [ ] Keep the user instructions accurate.
- [ ] Add two more test cases for the new event behavior.

## Stretch 2: Challenge Extension

- [ ] Use both keyboard and mouse events.
- [ ] Use a helper function to update state or display information.
- [ ] Add a clear win, reset, or mode-change behavior.
- [ ] Add two more test cases for combined events.
