## Required Friday Project

Build a small interactive turtle toy controlled by keys or clicks.

The goal is not to build the largest possible program. The goal is to show that you can use this week's textbook concepts correctly and explain your choices.

## Requirements I Will Check

Your program must include all of these:

- [ ] Create a turtle screen and turtle object.
- [ ] Define at least two event-handler functions.
- [ ] Connect handlers to keys or mouse clicks with event-listening methods.
- [ ] Use a state variable such as score, color, speed, or mode.
- [ ] Change something visible when an event happens.
- [ ] Print or display a short instruction for the user.
- [ ] Keep the program open long enough for interaction.
- [ ] Include at least three test cases in `notes.md` describing events you tried.

## Test Cases Required In `notes.md`

Include at least three tests like this:

```text
Test 1
Inputs or actions: what you typed, clicked, or changed
Expected result: what should happen
Actual result: what happened when you ran it
```

Your tests should show different paths or cases. Do not test the same behavior three times.
