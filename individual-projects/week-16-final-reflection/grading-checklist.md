# Grading Checklist For Week 16: Final Demo And Reflection

Branch to grade: `week-16-final-reflection`

## Required Project

- [ ] Use at least two major ideas from the course.
- [ ] Include at least one function or method.
- [ ] Use a list, file, event, or object structure.
- [ ] Program has clear input/output or interaction.
- [ ] Include a short demo script or instructions.
- [ ] Write a reflection in notes.md explaining what works and what you would improve.
- [ ] Code is organized and readable.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add polish: validation, clearer output, saved data, or a better user interface.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Add a substantial extension using objects, files, or event-driven interaction beyond the required version.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
