# Grading Checklist For Week 05: Turtle Pattern Drawing

Branch to grade: `week-05-turtle-pattern`

## Required Project

- [ ] Import turtle and create a turtle object.
- [ ] Use at least one for loop.
- [ ] Draw at least one repeated shape.
- [ ] Use range() to control repetition.
- [ ] Use at least two turtle commands such as forward, left, right, color, penup, or pendown.
- [ ] Use variables for at least one size or repeat count.
- [ ] Include comments that explain the pattern.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add color changes or multiple sizes using another loop.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Use nested loops to create a grid, spiral, or layered pattern.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
