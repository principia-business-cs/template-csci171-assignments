## Required Friday Project

Create a turtle drawing that uses loops to make a repeated geometric pattern.

## Requirements I Will Check

- [ ] Import turtle and create a turtle object.
- [ ] Use at least one for loop.
- [ ] Draw at least one repeated shape.
- [ ] Use range() to control repetition.
- [ ] Use at least two turtle commands such as forward, left, right, color, penup, or pendown.
- [ ] Use variables for at least one size or repeat count.
- [ ] Include comments that explain the pattern.

## Expected Result

The drawing visibly shows repetition or symmetry.
