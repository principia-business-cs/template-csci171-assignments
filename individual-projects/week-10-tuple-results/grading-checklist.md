# Grading Checklist For Week 10: Tuple Results Program

Branch to grade: `week-10-tuple-results`

## Required Project

- [ ] Define at least two functions that return tuples.
- [ ] Unpack at least one tuple into separate variables.
- [ ] Use a list of tuples or several tuple records.
- [ ] Print tuple data in a readable format.
- [ ] Explain in a comment why a tuple makes sense for one part.
- [ ] Do not mutate tuple values directly.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add a function that computes min, max, and average and returns them as a tuple.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Use tuple records to model coordinates or score data and calculate a useful result from them.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
