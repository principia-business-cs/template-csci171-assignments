# Week 10 Grading Checklist: Tuple Results

Use this as a quick grading aid alongside the student's code, notes, and PR.

## Required Project

- [ ] Create at least three tuples that represent records.
- [ ] Store the tuples in a list or another collection.
- [ ] Use tuple unpacking in a loop.
- [ ] Print each record with clear labels.
- [ ] Calculate at least one summary value from the records.
- [ ] Use indexing or unpacking to access tuple values.
- [ ] Explain in `notes.md` why a tuple is reasonable for this data.
- [ ] Include at least three test cases or sample records in `notes.md`.

## Stretch 1: Solid Extension

- [ ] Add ranked or sorted output based on one tuple field.
- [ ] Add one helper function that accepts a tuple.
- [ ] Keep tuple unpacking visible in the code.
- [ ] Add two more sample records or tests.

## Stretch 2: Challenge Extension

- [ ] Write a helper function that returns multiple values as a tuple.
- [ ] Unpack that returned tuple in `main()`.
- [ ] Add a small menu or filter option.
- [ ] Add two more test cases for the returned tuple or filter.
