# Grading Checklist For Week 07: Function Suite

Branch to grade: `week-07-function-suite`

## Required Project

- [ ] Define at least four fruitful functions.
- [ ] Each function must return a value instead of only printing.
- [ ] Use at least one Boolean function.
- [ ] Call each function with at least two test values.
- [ ] Print a simple test report or result table.
- [ ] Use parameters and meaningful names.
- [ ] No repeated copy/paste logic when a function should be reused.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add simple assert tests for each function.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Add edge-case tests and one composed function that calls two other functions.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
