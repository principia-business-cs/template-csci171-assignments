# Week 07 Grading Checklist: Function Suite

Use this as a quick grading aid alongside the student's code, notes, and PR.

## Required Project

- [ ] Define at least four functions besides `main()`.
- [ ] At least three functions must return a value.
- [ ] At least one function must return `True` or `False`.
- [ ] At least one function must use a parameter in a calculation or comparison.
- [ ] Store returned values in variables before printing at least twice.
- [ ] Print labeled test output for each function.
- [ ] Avoid using `input()` inside the helper functions; collect input in `main()` if needed.
- [ ] Include at least three test cases in `notes.md`, including one edge case.

## Stretch 1: Solid Extension

- [ ] Add at least two edge-case tests.
- [ ] Add one more Boolean helper function.
- [ ] Use an `if` statement in `main()` that depends on a returned Boolean value.
- [ ] Keep function names clear and specific.

## Stretch 2: Challenge Extension

- [ ] Add a simple menu that lets the user choose which function to run.
- [ ] Keep the calculations inside functions, not inside the menu logic.
- [ ] Use a loop so the menu can run more than once.
- [ ] Add two more test cases for menu choices.
