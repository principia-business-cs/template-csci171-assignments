## Required Friday Project

Build a number guessing game that repeats until the user guesses correctly or chooses to stop.

## Requirements I Will Check

- [ ] Use a while loop.
- [ ] Use a target number stored in a variable.
- [ ] Ask the user for guesses inside the loop.
- [ ] Give higher/lower feedback.
- [ ] Count the number of guesses.
- [ ] Stop when the user guesses correctly.
- [ ] Print a final message with the guess count.
- [ ] Avoid infinite loops.

## Expected Result

The game can be completed by a normal player in class.
