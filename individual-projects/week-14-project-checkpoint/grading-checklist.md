# Week 14 Grading Checklist: Project Checkpoint

Use this as a quick grading aid alongside the student's code, notes, and PR.

## Required Project

- [ ] Submit runnable code for the core behavior of your final mini-project.
- [ ] Use at least one list or collection to store data.
- [ ] Use at least one loop to process that data.
- [ ] Use at least one conditional to make a decision.
- [ ] Include a short algorithm plan in `notes.md` before or above your tests.
- [ ] Include at least one search, filter, count, or sort-style operation.
- [ ] Print enough output for someone else to verify the checkpoint works.
- [ ] Include at least three test cases in `notes.md`.

## Stretch 1: Solid Extension

- [ ] Add one planned stretch feature from your notes.
- [ ] Explain the algorithm for that feature in 3-5 sentences.
- [ ] Keep the core checkpoint behavior working.
- [ ] Add two more test cases for the stretch feature.

## Stretch 2: Challenge Extension

- [ ] Refactor repeated logic into helper functions.
- [ ] Add a second data-processing operation, such as search plus sort.
- [ ] Include a short trace of one loop in `notes.md`.
- [ ] Add two more test cases for the refactored behavior.
