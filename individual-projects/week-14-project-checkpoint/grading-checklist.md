# Grading Checklist For Week 14: Algorithm Clinic And Final Plan

Branch to grade: `week-14-project-checkpoint`

## Required Project

- [ ] Implement at least three list-processing functions.
- [ ] At least one function must search a list.
- [ ] At least one function must accumulate or summarize values.
- [ ] At least one function must find a best/worst value.
- [ ] Include test data and print test results.
- [ ] Write a short final project plan in notes.md.
- [ ] Explain one algorithm in your own words.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add hand-written trace comments for one algorithm.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Implement a challenge algorithm such as binary search on sorted data or selection sort with test output.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
