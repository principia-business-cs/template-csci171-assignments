# Grading Checklist For Week 11: Utility Module

Branch to grade: `week-11-utility-module`

## Required Project

- [ ] Create at least two Python files.
- [ ] One file must be a module with helper functions.
- [ ] The main file must import your module.
- [ ] Define at least four helper functions.
- [ ] Call each helper function from the main program.
- [ ] Use if __name__ == "__main__" in the main file or explain your program structure in comments.
- [ ] Keep helper functions reusable and not tied to one prompt.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add a short demo menu that calls different helper functions.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Add tests or a second program that imports the same module for a different purpose.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
