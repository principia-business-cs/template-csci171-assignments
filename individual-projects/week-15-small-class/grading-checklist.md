# Week 15 Grading Checklist: Small Class Model

Use this as a quick grading aid alongside the student's code, notes, and PR.

## Required Project

- [ ] Define one class with a clear name.
- [ ] Write an `__init__` method with at least two attributes.
- [ ] Create at least two objects from the class.
- [ ] Write at least two methods besides `__init__`.
- [ ] Call methods on your objects from `main()`.
- [ ] Show that object state can be read or changed.
- [ ] Print clear test output for each object.
- [ ] Include at least three test cases in `notes.md`.

## Stretch 1: Solid Extension

- [ ] Add a second class or a list of objects.
- [ ] Use a loop to call a method on multiple objects.
- [ ] Keep the original class behavior working.
- [ ] Add two more test cases for multiple objects.

## Stretch 2: Challenge Extension

- [ ] Add a method that compares, combines, or transfers information between objects.
- [ ] Use a helper function that accepts an object as a parameter.
- [ ] Add a meaningful `__str__` method or display method.
- [ ] Add two more test cases for object interaction.
