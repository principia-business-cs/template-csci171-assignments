# Grading Checklist For Week 02: Personal Calculator

Branch to grade: `week-02-calculator`

## Required Project

- [ ] Ask the user for at least three numeric inputs.
- [ ] Convert input strings to int or float before doing math.
- [ ] Calculate at least four results.
- [ ] Use variables with meaningful names for inputs and results.
- [ ] Print a labeled summary of the calculations.
- [ ] Include at least one comment explaining a calculation.
- [ ] Program runs without crashing for normal numeric input.

## Optional Stretch 1

This is optional extra credit designed for students who finish the required project and want more practice.

- [ ] Add one extra useful calculation and round at least one result.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what you added.

## Optional Stretch 2

This is optional extra credit designed for students who already know some programming and want a bigger challenge.

- [ ] Add a menu that lets the user choose between at least two calculator modes.
- [ ] Keep the required project working.
- [ ] Add a short note in `notes.md` explaining what was challenging.

## Quick Grading Notes

- Required project should be graded before stretch work.
- Stretch work should not rescue a broken required project.
- Give credit for clear, working code that demonstrates the textbook ideas for the week.
